# Default method footnotes for Hy's Law tables

Default method footnotes for Hy's Law tables

## Usage

``` r
default_hyslaw_footnotes(classified = NULL)
```

## Arguments

- classified:

  Optional list from
  [`classify_hyslaw()`](https://ygma-bitc.github.io/tm.hyslaw/reference/classify_hyslaw.md)
  used to fill window, comparison operator, and ALP settings.

## Value

Character vector of footer notes.
