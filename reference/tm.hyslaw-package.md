# tm.hyslaw: Teal Modules for Hy's Law Monitoring and eDISH Plots

Provides an open-source teal module and reusable builders for
exploratory Hy's Law monitoring from CDISC ADaM-style ADSL and ADLB.
Peak eDISH, mDISH, and cholestatic screening plots plus concurrent
ALT/AST plus bilirubin elevations (optional ALP exclusion) are
classified without depending on study-specific ADDILI datasets. Table
and plot builders can be called without launching Shiny.
